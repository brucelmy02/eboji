# eboji · e薄肌

一个在自己电脑上运行的 AI 健身训练原型。选择计划、查看动作卡和 3D 示范、记录完成情况，再通过反馈获得调整建议。

**主要操作都在网页中完成。** Codex 提供 AI 能力，也可以协助启动网页；每位使用者使用自己的电脑、登录和记录。

## 把 GitHub 链接交给 Codex 安装

如果你已经在自己的电脑上使用 Codex，可以让它帮你完成下载、环境检查、连接检查和网页启动。目前这套指引以 macOS 为主。

仓库地址：[brucelmy02/eboji](https://github.com/brucelmy02/eboji)。在 **Codex 的本机任务** 中发送下面这段话：

> 请帮我把 https://github.com/brucelmy02/eboji 安装到本机，按仓库 README.md 和 docs/CODEX_SETUP.md 配置好 Codex 连接并打开网页。优先使用我已有的 Codex 和 ChatGPT 登录；需要我登录时告诉我怎么操作。完成后告诉我下次怎样打开。

Codex 会按仓库中的安装流程检查缺少的环境，并在权限允许的范围内完成安装。你可能需要完成系统授权或官方账号登录。无需先手动安装 Skill，也无需在 eboji 网页中填写 API Key。这里安装的是完整的本地网页应用；Skill 的训练规则随项目一起提供。

安装后应得到 **网页地址、实际安装位置、Codex 登录检查结果和下次启动方式**。安装检查不会自动生成训练计划；检查登录成功也不等于已验证模型调用、网络和剩余额度。网页打开后，就可以按[第一次使用](#第一次使用)开始体验。

**版本状态：** 当前提供本机原型源码，尚未在全新电脑上验收从环境安装到真实 AI 生成的完整路径。下方也保留了手动安装方式，遇到问题可按[常见问题](#常见问题)排查。

## 先打开看看

如果你已经拿到完整项目，并安装了 Node.js 22 或更新版本：

1. 在 macOS 上打开项目文件夹，双击 `start.command`。
2. 等待出现“eboji 已启动”，浏览器会自动打开；没有自动打开时，访问 [本机 e薄肌](http://127.0.0.1:3000)。
3. 首页点击 **“先试预设计划”**，预览后采用一套，即可体验动作卡、动画和训练记录。这条路线无需登录 Codex，也不调用 AI。

使用期间保持启动时的终端窗口开启。退出网页不会删除记录；电脑重启或服务停止后，需要再次启动。

还没有准备好环境，请从下面的安装步骤开始。

## 安装与首次启动

### 第一步：保存完整项目

打开 [GitHub 仓库](https://github.com/brucelmy02/eboji)，选择 **Code → Download ZIP**，或使用开发者提供的完整项目目录。把压缩包解压到一个固定位置，例如“文稿”下的 `eboji` 文件夹；不要直接在压缩包预览中启动。

打开后应能看到：

```text
eboji/
├── README.md
├── package.json
├── server.mjs
├── start.command
├── lib/
├── public/
├── skills/
│   └── eboji/
│       └── SKILL.md
└── docs/
```

请保留完整的 `public/` 目录，其中包含网页、品牌图片、动作预览及 3D 资源。只下载 `SKILL.md` 无法运行本项目。

### 第二步：安装 Node.js

Node.js 是运行这个本地网站需要的程序。

1. 前往 [Node.js 官方下载页](https://nodejs.org/en/download)，选择适用于自己电脑的 LTS 安装程序；版本需为 22 或更新。
2. 按安装程序完成安装，然后重新打开“终端”。
3. 分别输入以下命令，确认能显示版本号：

```sh
node --version
npm --version
```

`node` 应显示 `v22.x.x` 或更高版本。如果显示找不到命令，先重新打开终端；仍不正常时，检查 Node.js 是否安装完成。

**eboji 本身没有需要另装的第三方运行依赖，因此不需要在项目里执行 `npm install`。**

### 第三步：启动网页

在 macOS 上，双击项目中的 `start.command`。看到“eboji 已启动：http://127.0.0.1:3000”后，打开该地址。

也可以从终端启动。先输入 `cd `（后面留一个空格），把项目文件夹拖入终端，再按回车，这样可以进入实际目录，无需手写路径。随后运行：

```sh
npm start
```

手动打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。这个地址指向当前电脑，只在本地服务运行时可用；直接把链接发给朋友，朋友不会访问到你的项目。

不要直接双击 `public/index.html`：网页需要通过本地服务读取和保存计划。

### 第四步：连接 AI（按需）

只体验预设可以跳过这一步，之后再配置。

如果电脑上已经有可用的 Codex，先启动网页。在已有计划后的 **“我的 → 本机 AI 连接 → 检查连接”** 中检查；页面显示“本机 AI 已连接”时即可使用 AI 功能。macOS 版本也会尝试寻找 Codex / ChatGPT 桌面应用中已存在的 CLI，但具体可用性以检查结果为准。

需要单独安装命令行工具时，可按 [Codex CLI 官方安装说明](https://learn.chatgpt.com/docs/codex/cli) 操作。已安装 Node.js 的用户，也可通过 npm 安装官方包：

```sh
npm install -g @openai/codex@latest
```

这里安装的是 Codex 工具，与前面“不需要安装 eboji 项目依赖”是两回事。官方也提供其他安装方式；npm 安装遇到权限问题时，可使用官方安装页中的其他方式。[官方 npm 安装示例](https://developers.openai.com/cookbook/examples/codex/using_goals_in_codex)

安装后，重新打开终端，分别运行：

```sh
codex --version
codex login
codex login status
```

按照登录页面提示，用自己的 ChatGPT 账号完成登录；最后一个命令应显示已登录。此路线无需在 eboji 中填写 API Key，能否使用 AI 仍取决于账号权限、剩余额度和网络。登录方式参见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/auth)。

安装或切换 Codex CLI 后，先确认网页没有正在进行的 AI 请求，再停止并重新启动 eboji，然后刷新页面。

## 通过 Codex 启动

已经下载完整项目时，按下面的方式启动；只有仓库链接时，先使用本文开头的安装请求。安装与连接检查的详细步骤在 [Codex 安装指引](docs/CODEX_SETUP.md)，训练过程仍在网页中完成。

1. 在 Codex 中打开完整的 `eboji` 项目文件夹，使用本机环境。
2. 将下面这段话发给 Codex：

> 请读取当前项目的 README.md、docs/CODEX_SETUP.md 和 skills/eboji/SKILL.md，按其中规则检查 Codex 连接，启动 e薄肌并打开网页。已有同一项目的服务就复用，没有才启动。不要修改我的训练记录，也不要为了验证启动而生成 AI 计划。若需要我完成登录或安装，请给出具体步骤。

3. 按提示完成缺少的环境准备或本地运行权限确认。
4. 打开 Codex 返回的实际本机地址，在网页里继续操作。

这段话是交给 Codex 的请求，不是终端命令。当前没有经过独立验证的后台常驻启动器；如果 Codex 启动的服务停止，请用上一节的终端方式启动并保持窗口开启。

本项目的 Skill 使用相对于项目的路径寻找网页和动作库，**不要只把这个 Skill 文件夹复制到个人技能目录**，否则可能找不到这些资源。Codex 的默认技能目录与插件分发方式见 [官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。可直接安装并自动识别的完整插件包仍待制作。

## 第一次使用

### 选择起步方式

首页提供两条路线：

| 路线 | 操作 | 是否调用 AI |
| --- | --- | --- |
| 先试预设计划 | 预览整周安排，选择经验并确认适用条件，点击“使用这套计划” | 否 |
| 定制我的计划 | 按三步填写资料，最后点击“生成我的计划” | 是 |

三套预设分别为：

| 预设 | 每周训练次数 | 每次预计时间 | 器械 |
| --- | --- | --- | --- |
| 轻量徒手起步 | 2 次 | 20 分钟 | 徒手、稳固墙面 |
| 徒手基础全身 | 3 次 | 30 分钟 | 徒手、稳固墙面 |
| 哑铃基础入门 | 3 次 | 30 分钟 | 轻哑铃、稳固墙面，无需训练凳 |

预设是固定的入门安排，不会因所填经验而重新计算动作或训练量，也不要求填写身高体重。采用另一套预设会生成新版本，原计划和反馈保留。当前记录存在运动限制时，页面会先引导确认适合的运动条件。

AI 定制依次询问目标与经验、身体情况、时间与器械。生理性别可以选“暂不填写”；“试填示例”只填写虚构资料，生成前应改成自己的真实情况。生成可能需要 1–4 分钟，可以取消；失败时会保留此前已保存的计划。

### 按卡组完成训练

1. 在“训练”页选择计划中的一天，点击“查看这次训练”。“第 1 天”是计划顺序，不表示必须在周一完成，也不会按日期自动推进。
2. 查看热身安排，再进入动作卡组。点击动作名称、左右箭头或拖动卡片可以切换动作。
3. 按需展开“查看 3D 动作示范”或“查看动作步骤与常见错误”。示范可以旋转、切换视角、播放、暂停和逐阶段查看。
4. 实际完成一组后，再点击“完成第 N 组”。需要组间休息时会出现倒计时；误点可以“撤销上一组”。
5. 查看放松与收尾；需要 AI 建议时，再记录训练感受。

卡组按计划版本和训练日保存进度，刷新后可以继续。再次练同一天时，点击“重新开始这一天”；误重置可点击“恢复刚才的进度”。重新开始不会抹掉已经留下的训练足迹。

### 反馈与调整

针对某个动作点击“反馈这个动作”，或在训练末尾点击“记录训练感受”。填写实际完成情况与感受，点击“获取 AI 建议”后才会提交给 AI。

已标记的组数会预填，提交前可以改正；次数和重量需要按实际情况填写。AI 可能给出建议、询问补充信息，或提出调整。先查看具体变化，再决定是否点击 **“采用这些调整”**；只有采用后才更新计划，并保留旧版本。

### 回看记录和训练足迹

- **记录**：回看训练反馈、AI 建议与历史计划版本。
- **我的**：查看训练资料、切换预设、检查 AI 连接，以及查看年度训练足迹。
- **训练足迹**：完成至少一组，或提交完成组数大于 0 的训练反馈，当天就会变绿；同一天只统计一次。点击格子可看当天记录，窄屏下可以横向滚动。

仅打开网页、浏览动作或生成计划不会点亮格子。旧版卡组进度没有日期的部分不会被补成今天的记录；已经保存的训练反馈可以按提交日期显示。

### 动作为什么优先来自动作库

项目有 80 个居家徒手和哑铃动作，提供统一的卡片、说明与动作示意。AI 的计划生成和反馈调整都要求先从适用的库内动作选择。

只有库内没有合适替代且确有必要时，才允许新增库外动作，并要求解释原因、给出基础做法和所需支持物。库外动作显示文字指导，不套用相似动作的动画。这是 AI 指令要求，并不代表所有输出都经过专业教练逐项审核。

## 下次如何继续

1. 双击 `start.command`，或进入同一项目目录运行 `npm start`；服务已经运行时直接打开网页即可。
2. 使用上次的浏览器、浏览器配置和网址。默认建议一直使用 `http://127.0.0.1:3000`。
3. 已有计划时会进入训练页，选择这次要练的训练日继续。

不必每次重新安装、重新填资料或重新生成计划。可以把页面加入书签，但书签不能代替启动服务。

结束使用时，先等待当前请求完成，或在页面里取消请求；随后在启动服务的终端中按 `Ctrl+C`。关闭网页标签本身不会停止服务，停止服务也不会清空已保存记录。

## 数据与额度

### 哪些操作会使用 AI 额度

| 操作 | 网页是否发起 AI 请求 |
| --- | --- |
| 浏览、采用预设，浏览动作库与动画 | 否 |
| 标记或撤销组数，回看记录与训练足迹 | 否 |
| 检查本机 AI 连接 | 否，只检查登录状态 |
| 生成定制计划、提交反馈分析、补充追问 | 是 |
| 采用已经生成的调整建议 | 否，保存已有建议为新版本 |

请 Codex 在聊天里协助安装或启动，属于一次 Codex 对话，与网页中的“预设不调用 AI”是两回事，也可能使用 Codex 额度。

通过 ChatGPT 登录时使用当前账号可用的 Codex 额度，会员并不代表无限使用。若你的 CLI 原本通过 API Key 登录，则遵循该 API 账号的计费方式；本项目不会把 API 登录自动切换成订阅登录。[认证与计费方式](https://learn.chatgpt.com/docs/auth)

AI 功能需要联网，会把本次相关的身体资料、计划和反馈发送给 Codex 服务；页面保存在本机不代表 AI 推理完全离线。浏览与采用预设无需 AI 请求。

### 记录保存在哪里

| 内容 | 保存位置 | 换浏览器后 |
| --- | --- | --- |
| 身体资料、计划版本、已提交反馈和 AI 分析 | 项目中的 `.eboji/state.json` | 同一项目服务仍能读取 |
| 卡组完成进度、休息状态、卡组训练足迹 | 当前浏览器对当前网址的本地存储 | 不会自动跟随 |

`localhost` 与 `127.0.0.1`、端口 `3000` 与 `3001` 是不同的浏览器存储空间。换网址后卡组进度看起来可能为空，但同一项目的服务端资料仍然存在。尽量固定使用同一个网址；当前不提供跨浏览器同步或卡组足迹导出。

备份资料、计划与反馈时，先停止服务，再复制 `.eboji` 文件夹到自己的备份位置。macOS 的 Finder 可按 `Command+Shift+.` 显示隐藏文件。这个备份不包含浏览器中的卡组进度与足迹；恢复资料也不会自动合并不同备份中的记录。

“我的 → 清空记录”会在确认后清除这个项目的资料、计划和反馈，以及当前浏览器当前网址下的卡组进度与足迹。此操作没有内置撤销功能。

## 常见问题

### 网页打不开，或关闭终端后网页就不能用了

确认已启动服务并看到“eboji 已启动”。保持终端窗口开启，并使用终端显示的地址。不要打开文件地址或把本机地址当作已经部署好的公网网站。

### 双击启动文件没有反应，或提示没有执行权限

进入项目目录后运行 `npm start`。如果仍提示找不到 `node` / `npm`，先完成 Node.js 安装并重新打开终端。双击启动文件只适用于 macOS。

### 提示端口已占用

如果已经打开同一份 eboji，直接使用已有服务即可；不要盲目停止其他应用。需要临时换端口时，可在 macOS 终端的项目目录运行：

```sh
PORT=3001 npm start
```

然后打开 [http://127.0.0.1:3001](http://127.0.0.1:3001)。换端口会使用另一份浏览器存储，原端口下的卡组进度与足迹不会同步显示。

### 已经登录 ChatGPT，页面为什么仍显示 AI 未连接

浏览器中的 ChatGPT 登录不等于命令行工具已经就绪。若 `codex` 命令可用，运行 `codex login` 和 `codex login status`，随后回到页面检查连接；若提示命令不存在，按前面的 CLI 安装步骤处理。

使用桌面应用内置 CLI、但终端找不到 `codex` 时，可以先在网页检查连接。仍失败时，用终端安装版 CLI 是更明确的排查路线；自定义安装位置可交给熟悉环境的人配置 `CODEX_BIN`。

### AI 一直生成、失败或提示额度不足

网页的单次请求最多等待约 4 分钟。可以取消后检查网络、Codex 登录状态和账号额度，再决定是否重试；已经发送的请求可能已消耗部分额度，取消不保证退回。也可继续浏览已有计划，或使用预设。

### 找不到 e薄肌 Skill

当前提供的是项目内规则文件，还没有自动安装注册。请在 Codex 中打开完整项目，并复制“通过 Codex 启动”里的请求，明确指定 `skills/eboji/SKILL.md`。仅输入 `$eboji` 不保证能找到它。

### 换浏览器后进度不见了，或今天没有变绿

先确认使用相同浏览器配置和网址，且实际标记完成过一组；看动作、开动画不会产生训练记录。足迹也会读取完成组数大于 0 的已保存反馈。隐私模式、清理浏览器数据或浏览器禁止存储，都可能影响本地卡组记录。

### 为什么没有显示 3D，或某个动作没有动画

不支持 WebGL 或加载失败时，已有库内动作会回退到 2D 分步示意；库外动作保留文字说明。请确认分发包保留了完整 `public/` 资源；也可以在支持 WebGL 的浏览器中重试。

### 能直接用手机打开，或者发链接让朋友用吗

当前服务只监听本机，手机上的 `127.0.0.1` 指向手机自己。朋友需要在自己的电脑上运行一份项目；当前没有远程访问、多人共享或云部署入口。

## 分享给其他人

分享完整的程序和资源文件，让对方使用自己的登录。**不要把自己的 `.eboji/` 训练资料一起发送。** `.gitignore` 会排除个人数据，但直接压缩整个目录时仍需单独检查压缩包内容。

分发包也应排除 `.artifacts/` 测试材料、`.env`、本地日志及任何账号凭据。当前未提供正式发布压缩包或一键插件安装器；收到文件的用户可按本文完成本机安装。

## 适用范围与开发资料

当前用于成年人一般健身体验。文字反馈和动作示意不能确认真实姿势是否正确，也不能诊断伤病；本版没有照片、视频或摄像头分析。存在疼痛或运动限制时，项目会引导先确认情况或获得专业评估。

想修改程序、生成动作预览或检查实现，参见 [开发说明](docs/DEVELOPMENT.md)。动作素材及参考来源见 [动作库说明](public/exercises/ATTRIBUTION.md)。
