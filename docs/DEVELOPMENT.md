# e薄肌开发说明

面向修改代码、验证功能与整理分发包的维护者。安装与使用请看 [README](../README.md)。以下源码路径均相对于项目根目录，命令也应在项目根目录运行。

## 验证与实现

```sh
npm run check
npm test
```

`public/` 是网页；`server.mjs` 提供本机接口；`lib/codex.mjs` 连接 Codex；`lib/plan.mjs` 和 `lib/feedback.mjs` 定义提示词、格式和校验；`lib/store.mjs` 保存记录。

`skills/eboji/SKILL.md` 保存随项目分发的 Skill 入口与动作选择约束，目前尚未打包或安装为插件。动作选择规则统一由 `lib/exercise-catalog.mjs` 提供：先查适用的库内动作，只有库内无合适替代且确有必要时才允许新增库外动作，并要求说明具体原因、基础做法与暂无动画；计划生成和反馈调整均复用此规则。这是 AI 指令约束，现有格式校验不能自动证明模型给出的例外理由成立。

`public/preset-plans.js` 提供前后端共用的固定模板；`lib/presets.mjs` 验证选择并克隆服务端模板。`GET /api/session` 只提供本地会话令牌，不查询 AI；`POST /api/preset` 只接受预设 ID、经验与适用条件确认，不接受客户端改写的动作计划。记录通过 `source` 区分 `preset`、`ai`、`ai-adjusted`，旧记录继续兼容。

品牌素材保存在 `output/brand/`，网页使用 `public/brand/` 中内容一致的副本：蓝色横版 `eboji-logo-blue-v2.png` 用于页头，蓝色独立图标 `eboji-mark-blue-v2.png` 用于浏览器标签页与 `/favicon.ico`，与页面的蓝色强调色保持一致。橙色 v1 原版及其旧访问路径继续保留。

界面采用 Apple 风格的简洁视觉：白底、浅灰分组面板、近黑文字和蓝色主操作，统一胶囊按钮、大圆角卡片与分段选择器。样式集中在 `public/styles.css`，保留三步建档、折叠动作详情和逐步反馈；手机输入文字使用 16px，最窄屏幕中的反馈操作纵向排列，并保留键盘焦点与减少动态效果设置。

页面按任务优先级组织：训练首页突出当次安排和主要入口；训练页默认展示热身，以编号连接动作练习、放松与练后反馈。设置步骤标明名称，生成前显示随选择更新的安排摘要。反馈表单区分必填组数与选填内容，器械重量按需展开。蓝色主要用于主操作与选中状态，辅助信息维持可读字号。

居家动作库收录 **80 个常用动作与基础变式**：52 个徒手、28 个哑铃，涵盖腿、臀、胸、背、肩、手臂、核心、全身活动与拉伸。它不是按使用频率统计的排行榜。欢迎页可直接浏览；已有计划后从顶部“动作库”进入，可搜索名称/肌群并筛选部位、器械、难度。

每张卡片提供基础步骤、要点、常见错误与原创动作示意。点开后默认使用立体人物，可拖动旋转、切换立体/正面/侧面/俯视、放大缩小、播放暂停、按阶段查看和半速播放。键盘聚焦模型后可用方向键旋转、加减键缩放。页面默认不自动播放；静态保持动作只演示进入姿势，不将反复屈伸当作保持。支持减少动态效果。计划中的准确匹配动作直接复用相同动画与说明；未覆盖的动作保留文字，不用相近变式冒充。

动作库、预设和训练卡组的静态预览统一使用现有 3D 场景导出的 WebP 图片（720 × 560，第二关键姿势、默认立体视角）。列表不创建 WebGL 场景；展开演示后才加载播放器。预览素材保存在 `public/exercise-posters/`，`manifest.json` 记录来源和校验值。

修改 3D 模型、姿势或灯光后，运行 `npm run posters:generate`，打开输出的本机链接并点击生成全部预览图；完成后关闭导出服务。这个导出工具只在手动运行时监听本机随机端口，网站本身不提供图片写入接口。生成完运行 `npm test` 检查素材完整性和来源一致性。

3D 采用本地 Three.js 0.186.1（MIT，许可见 `public/vendor/THREE-LICENSE.txt`），没有远程模型、CDN 或 AI 调用。动作打开并进入可见范围后才加载引擎、创建场景；离开屏幕、切页、收起卡片会释放场景资源。列表缩略图使用预先导出的 WebP 图片。不支持 WebGL 或加载失败时回退到原来的 2D 分步示意，不影响计划、文字要点和反馈。三维人物是动作路径示意，未声称真人动作捕捉或专业教练逐项认证。

`public/exercise-catalog.js` 是前后端共用资料；`public/exercise-poses.js` 定义二维预览与阶段标签，`public/exercise-poses-3d.js` 定义三维关节姿态，`public/exercise-renderer-3d.js` 绘制立体人物、器械与相机，`public/exercise-animation.js` 管理播放和资源生命周期，`public/exercise-catalog.css` 提供界面样式。`lib/exercise-catalog.mjs` 在计划生成和反馈调整时按器械、经验过滤候选，并要求 AI 优先使用标准名称。保留旧 JSON 格式与历史记录，不自动重写已有计划。动作基础资料参考 ACE、NASM、Mayo Clinic 等公开说明；素材和使用边界见 `public/exercises/ATTRIBUTION.md`。原来的 3 个动作静态 SVG 保留作为旧素材。

自动测试使用模拟模型输出，不消耗 Codex 额度。真实 AI 质量需要结合自己的训练反馈持续检验；结构校验无法证明训练内容或医学判断正确。

接入方式参考 [Codex 非交互模式官方文档](https://learn.chatgpt.com/docs/non-interactive-mode)。这是本机原型，每位使用者在自己的电脑上运行；部署为共享在线服务时，还需另行设计登录、计费、数据隔离和 AI 服务接入。

交互动效由 `public/motion.js` 与 `public/motion.css` 统一控制：页面与步骤轻入场、选择器滑动、动作详情按自然高度展开、反馈弹窗进出与滚动恢复。动画可被新操作打断；同页反馈保留底层动作展开状态，支持系统“减少动态效果”。相关生命周期回归检查在 `tests/motion.test.mjs`。
